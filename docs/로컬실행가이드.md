## 1. 한 줄 요약

로컬에서는 **프로세스 2개**를 동시에 켭니다.

| 프로세스 | 역할 | 기본 주소 |
|----------|------|-----------|
| **Backend** (FastAPI / uvicorn) | 대여소·날씨·코스·도로 API | http://localhost:8000 |
| **Frontend** (Vite) | 화면 + 카카오 지도 | http://localhost:5173 |

- **화면만** 보려면: Frontend만 켜도 지도 UI는 가능 (카카오 JS 키 필요).
- **대여소 마커·날씨 점수·추천 코스**까지 보려면: **Backend도 반드시** 켜야 함.
- API 키는 `.env`에만 두고 **Git에 올리지 않음**.

```
[브라우저] ──► Vite :5173  ──►  FastAPI :8000
                 │                    │
                 └─ Kakao Maps SDK    └─ mock / 공공 API (확장)
```

## 3. 최초 1회 세팅

### 3.1 저장소 받기 (이미 있으면 생략)

```powershell
git clone https://github.com/melody3212/ddareung_ddara2.git
cd ddareung_ddara2
```

### 3.2 Frontend 의존성

```powershell
cd frontend
npm install
copy .env.example .env
```

`frontend/.env` 예시 (값은 본인 키로 교체):

```env
VITE_API_BASE_URL=http://localhost:8000/api
VITE_KAKAO_JS_KEY=여기에_카카오_JavaScript_키
```

### 3.3 Backend 가상환경 · 의존성

```powershell
cd ..\backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

`backend/.env` 예시 (시크릿은 필요할 때만 채움):

```env
APP_NAME=따릉따라 API
ENV=local
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
DEFAULT_LAT=37.5665
DEFAULT_LNG=126.9780
```

> macOS/Linux 가상환경 활성화: `source .venv/bin/activate`  
> 복사: `cp .env.example .env`

### 3.4 카카오 지도 도메인 등록

1. [Kakao Developers](https://developers.kakao.com/) → 내 애플리케이션  
2. **앱 키**에서 **JavaScript 키** 확인 → `frontend/.env` 의 `VITE_KAKAO_JS_KEY`  
3. **플랫폼 → Web** 사이트 도메인 추가:

```text
http://localhost:5173
http://127.0.0.1:5173
```

도메인을 등록하지 않으면 지도 SDK 로드가 실패하거나 타일이 비어 보일 수 있습니다.

## 4. 매번 실행 방법 (일상 루틴)

**터미널을 2개** 엽니다.

### 4.1 터미널 A — 백엔드 켜기

```powershell
cd C:\Users\dal20\Desktop\ddareung_ddara\backend
.\.venv\Scripts\activate
uvicorn app.main:app --reload --port 8000
```

성공 시 로그 예:

```text
Uvicorn running on http://127.0.0.1:8000
Application startup complete.
```

| 확인 URL | 설명 |
|----------|------|
| http://localhost:8000/api/health | 헬스체크 JSON |
| http://localhost:8000/docs | Swagger UI (API 시험) |
| http://localhost:8000/api/stations | 대여소 mock 목록 |
| http://localhost:8000/api/weather | 날씨·라이딩 점수 |
| http://localhost:8000/api/courses | 추천 코스 |

`--reload` : 코드 저장 시 서버 자동 재시작.

### 4.2 터미널 B — 프론트 켜기

```powershell
cd C:\Users\dal20\Desktop\ddareung_ddara\frontend
npm run dev
```

성공 시 로그 예:

```text
VITE v6.x  ready
➜  Local:   http://localhost:5173/
```

브라우저에서 **http://localhost:5173/** 접속 → **시작하기** → 홈 지도.

### 4.3 스크립트로 켜기 (선택)

프로젝트 루트에서:

```powershell
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
```

(각각 새 터미널에서 실행 권장)

## 5. 끄는 방법

해당 터미널에서:

```text
Ctrl + C
```

- 백엔드만 끄면: 화면은 남지만 API 호출 실패  
- 프론트만 끄면: 화면 접속 불가, API는 `/docs` 로 계속 확인 가능

## 7. 환경 변수 · 시크릿 규칙

| 규칙 | 설명 |
|------|------|
| 커밋 금지 | `.env`, API 키, JWT, DB URL |
| 커밋 가능 | `.env.example` (값 비움 또는 더미) |
| 위치 | `frontend/.env`, `backend/.env` |
| 검사 | `git status` 에 `.env` 가 **보이면 안 됨** |

```powershell
git check-ignore -v frontend/.env backend/.env
```

ignore 로 나오면 정상입니다.

**절대 하지 말 것**

- 키를 소스 코드에 하드코딩  
- 키를 채팅/이슈/커밋 메시지에 그대로 붙이기  
- `.env` 를 force add 해서 푸시

## 8. 포트 · CORS

| 서비스 | 포트 |
|--------|------|
| Vite | 5173 |
| FastAPI | 8000 |

백엔드 포트를 바꿀 때:

```powershell
uvicorn app.main:app --reload --port 8001
```

동시에 `frontend/.env` 의 `VITE_API_BASE_URL` 도 `http://localhost:8001/api` 로 맞춥니다.  
`.env` 수정 후 Vite는 **재시작**해야 반영됩니다.

CORS: `backend/.env` 의 `CORS_ORIGINS` 에 프론트 origin 이 포함되어야 합니다.

```env
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

## 9. 문제 해결 (Troubleshooting)

### 9.1 지도가 안 뜸 / “지도 로드 실패”

1. `frontend/.env` 에 `VITE_KAKAO_JS_KEY` 있는지  
2. 카카오 콘솔 Web 도메인에 `http://localhost:5173` 등록  
3. **JavaScript 키**인지 확인 (REST 키와 다름)  
4. Vite 재시작 (`Ctrl+C` 후 `npm run dev`)  
5. 브라우저 개발자 도구 Console 에 카카오/네트워크 에러 확인  

### 9.2 대여소·날씨·코스가 안 뜸 / “API 연결 실패”

1. 백엔드 터미널이 살아 있는지 (`Uvicorn running...`)  
2. http://localhost:8000/api/health 가 `{"status":"ok",...}` 인지  
3. `VITE_API_BASE_URL` 이 `http://localhost:8000/api` 인지  
4. 방화벽/다른 프로그램이 8000 포트 쓰는지  

### 9.3 `.\.venv\Scripts\activate` 이 안 됨

- 경로가 `backend` 폴더인지 확인  
- 실행 정책:  
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`  
- 또는 직접:  
  `.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000`

### 9.4 `pip` / `python` 을 못 찾음

- Python 설치 시 “Add to PATH” 확인  
- `py -3 -m venv .venv` 시도  

### 9.5 포트 이미 사용 중

```powershell
# 8000 사용 프로세스 확인 (관리자 권한 필요할 수 있음)
netstat -ano | findstr :8000
```

다른 포트로 실행하거나 해당 PID 종료.
