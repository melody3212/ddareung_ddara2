## A. 기능 요약 (기획/구현 메모)

### 1. 자전거도로 시각화
- GeoJSON (`bikeload.geojson`) 표시
- 도로 ON/OFF 토글
- Kakao `Polyline` 렌더

### 2. 도로 유형 분류
- `VALUE_03` → `getCourseType()`
- 하천/공원형(초록) / 도로변형(빨강) / 기타(회색)

### 3. 안전성 중심 재분류
- 자전거전용차로 → 하천/공원형
- 겸용도로(비분리형) → 도로변형

### 4. 추천 코스 기준 (기획)
| 상황 | 방향 |
|------|------|
| 날씨 좋은 날 | 하천/공원형 비중↑ |
| 초보자 | 짧은 거리 + 하천/공원형 |
| 운동용 | 거리↑, 혼합 허용 |
| 도심 감성 | 도로변형 일부 포함 |
| 루프 산책 | 닫힌 경로 선호 |

필터: 도로타입, 거리, 도심 여부, 루트 형태

### 5. 향후
- 길찾기 · 단절 연결 · 속도별 시간 · Capacitor 앱
