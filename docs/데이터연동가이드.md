## 2. 따릉이 대여소

### 출처

- 포털: https://data.seoul.go.kr/
- 데이터: **서울시 공공자전거 따릉이 실시간 대여정보** (OA-15493)
- 페이지: https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do

### API

```text
http://openapi.seoul.go.kr:8088/{인증키}/json/bikeList/{시작}/{종료}/
```

예시:

```text
http://openapi.seoul.go.kr:8088/{KEY}/json/bikeList/1/1000/
http://openapi.seoul.go.kr:8088/{KEY}/json/bikeList/1001/2000/
```

- 한 번에 **최대 1000건**
- JSON만 지원
- 주요 필드: `stationId`, `stationName`, `stationLatitude`, `stationLongitude`, `parkingBikeTotCnt`, `rackTotCnt`, `shared`

### 키 발급

1. https://data.seoul.go.kr/ 회원가입·로그인  
2. 위 데이터셋에서 **인증키 신청**  
3. `backend/.env` 에 설정:

```env
SEOUL_OPENAPI_KEY=발급받은_키
```

4. 백엔드 재시작 (`uvicorn ...`)

### 우리 API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/stations` | 대여소 목록 (실시간, 서버 캐시 ~90초) |
| GET | `/api/stations/meta` | 출처·건수·키 설정 여부 |
| GET | `/api/stations/{id}` | 단건 |

키 없을 때: `sample` 시도 → 실패 시 **mock** 폴백.

## 3. 자전거 도로

### 기획에서 기대한 형태

- 서울 자전거 도로 노선 **GeoJSON / polyline**
- 구간 위치, 길이, 전용/겸용 등

### 실제 제공 현실 (2026 기준)

| 소스 | 형태 | 비고 |
|------|------|------|
| 서울 열린데이터광장 | 통계·안내지도 위주 | 과거 공간정보 일부 **종료** 안내 있음 |
| 스마트서울맵 | OpenAPI / SHP·GML | 키 신청, 테마 조회 후 GeoJSON 변환 가능 |
| **생활안전지도 Safemap** objtId=219 | **WMS 이미지** `IF_0101_WMS` | REST 좌표는 「제공 준비중」 |

→ 카카오맵에 **선 좌표를 바로 꽂는 OpenAPI** 가 열린데이터 `bikeList`처럼 단순하지 않음.

### 우리 현재 방식 (원본 프로젝트 이식)

원본 폴더 `Desktop/ddareung-ddara` 와 동일:

1. 정적 파일: `frontend/public/data/bikeload.geojson` (~2.8MB)
2. 로드: `fetch('/data/bikeload.geojson')`
3. `VALUE_03` → `getCourseType()`  
   - 하천/공원형 (초록)  
   - 도로변형 (빨강)  
   - 기타 (회색)
4. `GeometryCollection` 내 `LineString` → 카카오 `Polyline`
5. UI: 우측 상단 도로 ON/OFF 토글 (`MapLayerToggles`)

코드: `frontend/src/lib/bikeRoad.ts`, `KakaoMap.tsx`

| 분류 규칙 (VALUE_03) | 타입 |
|----------------------|------|
| 전용도로 (차도높이형 제외), 전용차로, 겸용(분리형) | 하천/공원형 |
| 우선도로, 차도높이형, 겸용(비분리형) | 도로변형 |
| 그 외 | 기타 |

### 백엔드 WMS (선택·레거시)

Safemap WMS 프록시는 `backend/app/api/bike_paths.py` 에 남아 있으나,  
지도 표시의 **주 경로는 GeoJSON Polyline** 입니다.

### 이후 고도화 옵션

1. 추천 엔진 (`recommend.js`) 이식 — 세그먼트 그래프 + 단절 점프  
2. 줌 레벨별 간소화 / 타일 분할  
3. PostGIS bbox 쿼리
